# Cloud Familiarity for a Data Analyst
## BigQuery + SQL (Skill-Showcase Project)


### 📌 Project Overview
This project demonstrates my hands-on familiarity with cloud-based data analytics, specifically using Google BigQuery and SQL.

The primary objective is not deep business analysis, but to showcase how a Data Analyst:

- Works inside a cloud data warehouse
- Ingests and cleans data using SQL
- Writes cost-efficient, structured queries
- Follows a clear, reproducible workflow in a cloud environment

### 🎯 What This Project Proves

- Comfort working inside BigQuery Studio
- Understanding of cloud data ingestion
- Ability to perform sanity checks and data cleaning using SQL
- Awareness of query cost and efficiency (no SELECT *, correct granularity, early filtering)
- Clear separation between raw data and clean analytical tables

### 🗂️ Workflow Followed

1. Uploaded CSV data into BigQuery as a raw table
2. Performed sanity checks to validate schema and data integrity
3. Cleaned and standardized data into a sales_clean table
4. Ran lightweight analytical queries to validate cleaned cloud data
5. Aggregated results by category, region, and time (monthly)

⚠️ The analysis layer is intentionally shallow.
Advanced analytics are covered in other skill-showcase projects and end-to-end projects elsewhere in the portfolio.
